# Seasonal Agriculture Performance Analysis

## Project Overview

This project analyzes seasonal agricultural data across Kharif, Rabi, and Zaid seasons using Python and Google Colab. The dataset was cleaned, analyzed, and visualized to identify seasonal trends in crop yield, revenue, rainfall, and other agricultural factors.

## Technologies Used

* Python
* Google Colab
* Pandas
* NumPy
* Matplotlib
